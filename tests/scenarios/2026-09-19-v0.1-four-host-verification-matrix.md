## Required checks on every host variant

The implementation leaf owns a fresh host session for each row below. The run
records host version, Backplane revision, upstream package source and version or
checkout commit, `gh` capability result, installed skill identities, and
`PASS`, `FAIL`, or `UNKNOWN`. It checks clean install, adoption of compatible
upstream, repeat install, setup preflight, update, rollback, uninstall, and
failure with dirty, unknown, duplicate, or incompatible state. It verifies
upstream `using-superpowers` plus `managing-superpowers-backlog` and
`managing-superpowers-handoffs` from separate installations. Unrelated plugin
entries, user files, and the independent upstream installation survive
Backplane changes. The host leaf also runs the five named conformance checks
and authorized lifecycle scenarios on disposable or authorized test issues.
