## Review Focus

1. A native upstream marketplace package has no Git checkout: Task 1 checks provenance, version or
   revision, and fresh skill discovery without requiring a clone.
2. A package has unknown provenance, no observable version or revision, or conflicts with another
   install: Task 1 scores compatibility unknown and preserves the existing install.
3. A sibling checkout is dirty or points to a lookalike origin: Task 1 requires rejection and no
   overwrite.
4. OpenCode is below V1 1.18.29 or V2 2.0.4: Task 2 assigns a negative host test and requires an
   unsupported result.
5. An issue has revision drift, multiple lifecycle labels, or a new blocker: Task 3 stops the
   transition and requires reconciliation.
