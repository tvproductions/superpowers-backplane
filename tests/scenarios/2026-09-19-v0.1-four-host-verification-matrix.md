## Required checks on every host variant

Codex issue #3 owns its completed fresh-host suite. For Claude Code and
OpenCode V1 and V2, the bounded prerequisite leaves collectively own the
fresh-session checks for each supported variant. Final #11 and #12 acceptance
verifies the integrated candidate and reruns an affected check when its
package, guide, host, upstream, or GitHub CLI input changed.

Each run records host version, Backplane revision, upstream package source
and version or checkout commit, GitHub CLI capability result, installed skill
identities, and PASS, FAIL, or UNKNOWN per check. The checks cover clean
install, adoption of compatible existing upstream, repeat install, setup
preflight, pinned update, rollback, Backplane-only uninstall, and failure
with dirty, unknown, duplicate, or incompatible state. A fresh session
discovers upstream using-superpowers and both Backplane skills from separate
installations. Unrelated plugin entries, user files, and the independent
upstream installation survive Backplane changes. The owning leaves also run
the five named conformance checks and authorized lifecycle scenarios on
disposable or explicitly authorized test issues. Every mandatory
supported-host check must PASS; unresolved FAIL or UNKNOWN blocks final
acceptance.
